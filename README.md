🚀 About Pengu IDE Pro

Pengu IDE Pro is built for developers who want more freedom in their development workflow.

Traditional Android development often requires a powerful computer, complex development environments, and additional tools. Pengu IDE Pro aims to bring essential development capabilities into a compact, mobile-friendly environment.

Whether you're creating a new Android application, editing source code, managing dependencies, or working with native C/C++ components, Pengu IDE Pro provides a unified workspace to support your development journey.

Our vision is simple: Make Android development accessible, portable, and productive.

---

✨ Core Features

Feature| Description
📝 Smart Code Editor| A streamlined coding experience with syntax highlighting, automatic indentation, and support for Java, XML, C, and C++.
⚡ Offline Build Engine| Build Android applications locally on your device without relying on cloud build servers.
📦 Dependency Management| Work with Maven dependencies and local AAR/JAR libraries.
🛠️ Native Development| Support for Android NDK workflows and native C/C++ development.
🤖 AI Coding Assistant| Get assistance with writing, understanding, debugging, and improving code.
🔐 APK Signing| Sign application packages using custom JKS or Keystore files.
📁 Project Management| Create, organize, import, and manage Android development projects.
📱 Mobile-First Workflow| Develop and manage your projects directly from your Android device.

🏗️ Development Capabilities

Pengu IDE Pro brings multiple parts of the Android development workflow together.

- Project Creation: Start new Android projects using available templates.
- Source Code Editing: Organize and edit project source files.
- Resource Management: Work with XML layouts, drawables, themes, and application resources.
- Library Integration: Manage external dependencies and local libraries.
- Native Integration: Work with JNI, C, C++, and NDK-based components.
- Build Workflow: Compile and package Android applications locally.
- Application Signing: Prepare signed APKs using your own signing credentials.

📲 Getting Started

1. Download

Visit the "GitHub Releases" (https://github.com/404sakib/PenguIDEPro/releases) page and download the latest available APK.

2. Install

Install Pengu IDE Pro on your compatible Android device. Allow installation from your chosen APK source if Android requests permission.

3. Create a Project

Open Pengu IDE Pro and select an available project template, such as:

- Empty Activity
- AppCompat
- C++ Native

4. Start Coding

Write your Java, XML, C, or C++ code and organize your project resources.

5. Build Your Application

Use the available build workflow to compile and package your Android application.
